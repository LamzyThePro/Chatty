How to install this update
  1. Choose your CURRENT Chatty file. When the file picker opens, select the Chatty-v1.0.12.html file you are using now.
  2. Click Save, then click Replace when Chrome asks about replacing the existing file.
  3. Chatty downloads the new version and checks its version and SHA-256 checksum.
  4. Chatty replaces the selected current file and reloads.
Do not select the new update download. Select the older/current Chatty file you opened to run this app. Do not select a Worker script.
First-time setup: choose the current Chatty HTML file you are running (for example, Chatty-v1.0.12.html), then approve access. Chatty verifies the new download before replacing that file.
